## Basics

제가 Cisco Packet Tracer를 처음 접하는 것이라 차근차근 배운 것들을 정리하겠습니다. 

![](/images/w3_lab1/1775544468459.png)스프트웨어를 킨 후 왼쪽 밑에 보이는 부분들이 우리가 쓸 수 있는 **장치**들입니다. 예를 들면, 서버 하나, 라우터 하나, PC 하나를 골라 Client-Server Architecture를 만들 수 있습니다. 

> 1\. 어떠한 장치가 필요할 때 왼쪽 밑에서 구하면 된다는 점

![](/images/w3_lab1/1775551468029.png)![](/images/w3_lab1/1775551457044.png)그리고, 제가 PC를 선택해서, icon 위에 눌러보면 외쪽에 있는 Module들을 설치할 수 있었습니다. 게다가, 컴퓨터 전원을 끄고, 킬 수 있더라고요. 랜 포트를 추가하거나 빼려면 전원을 꺼야 할 수 었어요.

> 2. 모든 장치는 실제 처럼 customization 할 수 있다는 점

![](/images/w3_lab1/1775552328153.png)여기는 2개의 PC를 서로 랜선으로 연결하여 IP 주소 설정 해봤습니다. 

> IP Configuration 하기 위해 PC를 눌러 Desktop 탭으로 들어가면 왼쪽 상단에 있습니다. 

![](/images/w3_lab1/1775552907372.png)제가 처음이지만 나와 있는 장치들을 사용해 위와 같은 topology를 만들었습니다. 컴퓨터네트워크 과목 들을 때 이러한 topology를 상상하려고 고생 많이 했는데 이런 소프트웨어를 일찍 알았으면 좋았을 탄데...

> Cisco Packet Tracer를 사용해 네트워크 topology를 실제 세계처럼 구현할 수 있습니다. 이론과 같이 이렇게 topology 만들고 네트워크 설정 해보면 지식을 그대로 얻을 수 있을 것 같네요

### ✍️ 마무리 (Conclusion)

이번 실습을 통해 **Cisco Packet Tracer**를 사용하여 네트워크 토폴로지를 직접 구성하고, 장치 간 통신 과정을 눈으로 확인해볼 수 있었습니다. 단순히 이론으로만 배울 때보다, 실제로 장치를 연결하고 IP를 설정해보면서 네트워크의 동작 원리를 훨씬 더 직관적으로 이해할 수 있었습니다.

특히, PC나 라우터와 같은 장치들을 직접 구성하고 설정하는 과정에서 **클라이언트-서버 구조와 기본적인 네트워크 흐름**을 자연스럽게 익힐 수 있었던 점이 인상적이었습니다. 앞으로 더 다양한 토폴로지와 프로토콜을 실습해본다면, 네트워크에 대한 이해도를 한층 더 높일 수 있을 것 같습니다.

이처럼 Cisco Packet Tracer는 네트워크를 처음 배우는 입장에서 매우 유용한 학습 도구이며, 이론과 실습을 연결해주는 중요한 역할을 한다고 느꼈습니다. 앞으로도 꾸준히 활용하면서 네트워크 설계와 구성 능력을 키워나가야겠습니다.
