## Server-Client Architecture

- **Client**  
  단어 그대로 해석하면 “사용자”로 오해하기 쉽지만, 소프트웨어 관점에서 Client는 **요청(Request)을 보내는 주체**입니다.  
  예를 들어 Web Browser나 Mobile App이 대표적인 Client입니다.  

  > 데이터를 요청하는 소프트웨어 = Client

- **Server**  
  Server는 데이터를 제공하는 시스템으로, Client의 요청을 받아 처리한 후 결과를 응답(Response)으로 돌려줍니다.  

> Client가 요청을 보내고 Server가 이를 처리하여 응답을 반환하는 구조를 **Client-Server Architecture**라고 합니다.

## What Exactly Does a Server Do?

서버는 단순히 데이터를 보내는 것이 아니라, 다음과 같은 과정을 반복합니다.

1. **대기 상태 (Listening)**  
   서버는 실행되는 순간부터 계속해서 요청을 기다립니다.  
   이를 “Listen for requests”라고 하며, 일종의 *입구를 지키는 역할*이라고 볼 수 있습니다.

2. **요청 처리 (Processing)**  
   요청이 들어오면 입력 데이터를 받아 개발자가 정의한 로직을 실행합니다.  
   예를 들어 버튼을 클릭했을 때 특정 동작이 수행되는 것이 바로 이 로직입니다.

3. **데이터베이스 사용 (Database Interaction)**  
   서버는 데이터를 직접 저장하기보다는 데이터베이스와 연결하여  
   데이터를 조회, 추가, 수정, 삭제합니다.

4. **응답 반환 (Response)**  
   처리된 결과를 다시 Client에게 전달합니다.

## Types of Server

서버의 종류를 이해하기 전에, 왜 서버가 여러 개로 나뉘는지 먼저 살펴보겠습니다.

하나의 서버에서 모든 작업을 처리하면 다음과 같은 문제가 발생합니다:

1. 모든 작업을 혼자 처리하기 때문에 **속도가 느려짐**
2. 하나의 오류로 인해 **전체 시스템이 다운될 수 있음**
3. 보안 침해 시 **모든 데이터가 위험해짐**

이러한 문제를 해결하기 위해 서버를 역할별로 나누어 사용합니다.

### 1. Web Server
Client의 HTTP/HTTPS 요청을 받아 HTML, CSS, JS 파일을 응답으로 제공합니다.  
(예: Apache HTTP Server, Nginx)

### 2. Application Server
비즈니스 로직을 수행하며 Web Server와 Database 사이를 연결합니다.  
(예: Node.js, Django)

### 3. Database Server
데이터를 저장하고, 데이터 관련 요청을 처리합니다.  
(예: MySQL, MongoDB)

### 4. Mail Server
이메일 송수신을 담당하는 서버입니다.

## Server Operating System

서버는 일반 PC와 달리 **서버 환경에 최적화된 운영체제(Server OS)** 를 사용합니다.  

그 이유는:
- 24시간 365일 안정적으로 동작해야 하고  
- 동시에 많은 요청을 처리해야 하기 때문입니다  

또한 대부분 GUI 없이 **터미널 기반으로 제어**됩니다.

대표적인 Server OS는 다음과 같습니다.

### 1. Ubuntu Server
가장 널리 사용되는 Linux 기반 OS로, 무료이며 학습 자료가 풍부해 입문자에게 적합합니다.

### 2. Windows Server
GUI 환경을 제공하며 Microsoft 생태계(.NET 등)와의 호환성이 뛰어납니다.

### 3. Red Hat Enterprise Linux 
기업용으로 설계된 Linux OS로 높은 안정성과 공식 지원을 제공합니다.

## Server Virtualization

현대 서버 환경에서는 하나의 물리 서버만 사용하는 것이 아니라,  
**가상화(Server Virtualization)** 기술을 활용하여 여러 서버를 효율적으로 운영합니다.

서버 가상화란  
👉 하나의 물리적 컴퓨터를 여러 개의 가상 서버로 나누는 기술입니다.

각 가상 서버는 독립적인 서버처럼 동작하며, 서로 영향을 주지 않습니다.


```
Physical Hardware
        ↓
Hypervisor
        ↓
Virtual Machines (VMs)
        ↓
각각 독립적인 Server OS 실행
```
대표적인 가상화 기술로는 VMware, VirtualBox, KVM 등이 있습니다.


대표적인 기술:
- VMware  
- VirtualBox  
- KVM  

### Server Virtualization의 장점

1. **자원 효율성**  
   하나의 서버를 여러 개로 나누어 활용 가능  

2. **격리 (Isolation)**  
   하나의 서버 장애가 전체에 영향을 주지 않음  

3. **확장성 (Scalability)**  
   필요에 따라 서버를 빠르게 생성/삭제 가능  

4. **비용 절감**  
   물리 서버 수를 줄여 비용 절약
