## 🏁 마무리

이번 실습에서는 AWS VPC의 기본 구성 요소들을 직접 만들어보고, **Public Subnet과 Private Subnet 환경에서 네트워크 통신이 정상적으로 이루어지는지** 단계별로 확인해봤습니다.

우리는 다음과 같은 전체 흐름으로 구성했습니다:

1. **VPC 생성** – 새로운 네트워크 공간을 만들고 네트워크 CIDR을 정의
2. **Routing Table 생성 및 Subnet 연결** – Subnet이 어떤 경로로 트래픽을 보낼지 결정
3. **ACL 설정** – 네트워크 계층에서 인바운드/아웃바운드 규칙 관리
4. **Public Subnet 생성** – 인터넷과 직접 통신 가능한 서브넷 구성
5. **Internet Gateway 연결 & Routing Table 수정** – 외부 IPv4 인터넷과 연결
6. **Security Group 설정** – 인스턴스 단위로 보안 규칙 제어
7. **EC2 생성 및 연결 테스트** – Public Subnet의 통신 정상 여부 확인
8. **Private Subnet 구성** – 외부로 나가기 위해 NAT Gateway 사용
9. **Private EC2 간 ping 테스트** – Private Subnet 내부 통신 검증

실습을 통해 다음 내용을 이해할 수 있었습니다:

- **Public Subnet은 IGW + Public IP → 외부 인터넷과 직접 통신 가능**
- **Private Subnet은 NAT Gateway 필요 → 외부로 나갈 수 있지만 외부에서 들어올 수 없음**
- **ACL(NACL)은 Subnet 단위, Security Group은 인스턴스 단위로 작동**
- **Routing Table 연결이 되어 있어야 통신 경로가 형성됨**

Public과 Private Subnet의 핵심 차이점을 직접 실습을 통해 확인함으로써, AWS 네트워크 구조의 기본 개념을 확실히 이해할 수 있었습니다.
